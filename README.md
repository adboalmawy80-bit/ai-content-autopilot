# 🚀 AI Content Autopilot (OmniPublish Core)

An enterprise-grade, secure AI Content Automation System featuring real-time data encryption, backend authentication, and an interactive UI.

---

## 🌟 Key Features

* **🔒 Enterprise Security**: 
  * Real-time **AES-256-CBC** data encryption at rest for sensitive content stored in MySQL.
  * **Helmet** integration for securing HTTP headers.
  * **Rate Limiting** to prevent DDoS attacks and spam.
* **⚡ Robust Backend**: Powered by Node.js & Express with connection pooling (`mysql2/promise`).
* **🎨 Modern UI**: Responsive Glassmorphic design with animated backgrounds and interactive authentication controls.
* **🗄️ Automated Database Initialization**: Automatic schema and table creation upon server startup.

---

## 🛠️ Tech Stack

* **Backend**: Node.js, Express.js
* **Database**: MySQL
* **Security & Auth**: Crypto (AES-256-CBC), Helmet, Express Rate Limit
* **Frontend**: HTML5, Modern CSS3 (Glassmorphism), JavaScript (Fetch API)
